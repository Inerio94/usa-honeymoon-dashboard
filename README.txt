USA HONEYMOON DASHBOARD

Carica questi 3 file nella ROOT del repository GitHub:
1. index.html
2. manifest.webmanifest
3. sw.js

Poi:
GitHub > Settings > Pages
> Build and deployment: Deploy from a branch
> Branch: main
> Folder: / (root)
> Save

Dopo la pubblicazione avrai un link HTTPS.
Su iPhone: Safari > Condividi > Aggiungi alla schermata Home.
